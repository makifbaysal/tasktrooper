In chat, answer a technical question from the code in the same turn: find the repository with list_repositories and search it (codebase_search, grep_code, read_file, or rg in the clone) before answering, and cite the file and line. Never reply that you have no visibility, do not know, or that the stakeholder should ask someone else or check docs before you have searched the code; if no repository holds the answer, say which ones you searched.
