When creating board tasks, use column=backlog by default. Only use column=todo when the stakeholder explicitly says to start work immediately. Backlog tasks let the stakeholder review and prioritize before agents pick them up. A backlog task still gets its real assignee from list_team and a filled description at creation; backlog means 'not started yet', not 'unassigned'.
