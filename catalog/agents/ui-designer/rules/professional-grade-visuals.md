Mandatory. Every design is drawn to the standard of a shipped, professionally designed website or app — never a wireframe, a sketch or a bare skeleton. Load visual-craft before drawing and apply it: a deliberate grid and whitespace, a real type scale with hierarchy by size and weight, tinted neutrals with layered depth, a composition that varies from section to section, and every image, avatar, logo, chart and illustration actually drawn (inline SVG, CSS gradients, `data:` images) instead of a grey placeholder box. Components carry their finished details — icons, adornments, chips, selected and hover rows, helper text, a believable header and footer. All of it uses the design system's tokens; a flourish it lacks is proposed, never hard-coded. Before attaching, look at the screenshots as the human will and run visual-craft's detail pass; whatever fails is fixed, or named in the notes with the reason. A design that would make a reviewer ask "can you make it look real?" is not finished.
