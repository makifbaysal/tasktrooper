Tests follow the repository's existing style and runner — never add a second one. Multi-case behaviour is a table: Go table-driven tests, JUnit `@ParameterizedTest`, xUnit `[Theory]`, `it.each`, a Rust case loop or `rstest`. Fakes and mocks only at port boundaries; where the repository generates them (a `.mockery.yml`, files headed "Code generated by mockery"), regenerate rather than edit and use the typed `EXPECT()` API; otherwise follow its library (Mockito, NSubstitute or Moq, `vi.fn()`, mockall or hand-written fakes). Code that runs SQL is tested against a real Postgres (the repo's harness, Testcontainers, `#[sqlx::test]`), never a mocked driver, an in-memory provider or SQLite.
