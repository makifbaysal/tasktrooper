Progress of one study: its kind and inputs, its status, the interview script and whether it is ready, how many people answered, how many could not, any error, and the follow-up questions asked so far with the answers. A study takes a few minutes to tens of minutes depending on the number of people; report progress and check back later instead of waiting. When `status` is done, read study_report; when it is interviewed, the report is still to be written (see study_report).
